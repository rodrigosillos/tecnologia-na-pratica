Este apoio acompanha **Python na Prática — Automatize tarefas, integre IA e transforme dados em relatórios**. Comece pelo capítulo 1 do livro para compreender os dados e as regras. A programação começa em `cap02`; o projeto final está em `cap12`.

## Preparar a pasta

Extraia as pastas `cap02` a `cap12` lado a lado em `projetos\python-na-pratica`, dentro de sua pasta de usuário. A raiz deve conter diretamente `cap02`, `cap03` e as demais pastas. A `.venv` será criada ao lado delas; não vem no ZIP.

Na primeira passagem, siga o capítulo 2 para instalar Python 3.14.7, criar o ambiente e selecionar o interpretador. Os comandos dos capítulos partem dessa raiz. Cada README fornece os detalhes de instalação da etapa. Use os requisitos do capítulo atual, sem substituir versões silenciosamente.

## Executar e conferir

Leia `GUIA_EXECUCAO.md`, o README e `ROTEIRO_WINDOWS.md` da etapa. Os modelos `REGISTRO_WINDOWS_MODELO.md` são formulários para sua execução, não relatórios já preenchidos. Guarde as evidências que produzir na pasta `evidencias` de cada capítulo.

Os esquemas `tnp_cap06`, `tnp_cap11` e `tnp_cap12` são independentes. Preparar um esquema existente não apaga seus dados. Na repetição dos exercícios, escolha novos destinos para saídas que recusam sobrescrita.

O percurso principal não precisa de chave de IA. As respostas sintéticas são identificadas nos arquivos; os testes não representam inferências reais. Chamadas autenticadas são extensões opcionais, com confirmação explícita, registro e revisão.

Consulte `VERIFICACAO_RESUMO.md` para o estado recebido no Windows. `MANIFESTO_DISTRIBUICAO_SHA256.json` relaciona os arquivos desta distribuição; os manifestos de cada capítulo preservam a identidade técnica das revisões de origem.
