# Procedimentos fictícios de prestação de contas

Material sintético de estudo. Complementa a política desta mesma versão.

## [PROC-001] Prazo de envio

O prazo para enviar a solicitação e o comprovante é de cinco dias úteis após a atividade profissional. Se faltar documento, a solicitação permanece pendente de revisão. Este material não define feriados nem uma regra de calendário para calcular uma data final.

## [PROC-002] Correção de registros

Uma correção deve preservar o registro original, identificar o campo alterado e registrar a justificativa. Se a despesa já tiver sido importada, não se deve substituir silenciosamente um registro com o mesmo identificador e dados diferentes. A divergência exige revisão antes de nova importação.
